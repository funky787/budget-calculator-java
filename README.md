# Калькулятор бюджета на Java


## Использовал

- Java 21
- Spring Boot
- Maven
- JUnit 5
- MockMvc
- JaCoCo

## Что сделано

Написал 6 тестов для проверки расчётов:

1. Обычный расчёт без страховки.
2. Расчёт со страховкой 5%.
3. Отрицательное количество дней.
4. Нулевая стоимость дня.
5. Расчёт с дробными числами.
6. Нулевое количество дней.

В расчёте страховки была ошибка: сумма умножалась на 5 вместо добавления 5%. Исправил умножение на 1.05.

## Запуск тестов

```bash
mvn test
```

Для проверки покрытия:

```bash
mvn clean verify
```

Отчёт находится в `target/site/jacoco/index.html`.

## Результат

Все 6 тестов проходят. Покрытие веток контроллера — 100%.
