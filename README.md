# Budget Calculator

Небольшой проект на Java для расчёта бюджета на определённое количество дней.

Пользователь указывает стоимость одного дня, количество дней и нужно ли добавлять страховку. Программа рассчитывает итоговую сумму. Если страховка включена, к стоимости прибавляется 5%.

## Что используется

- Java 21
- Spring Boot
- Maven
- JUnit 5
- MockMvc
- JaCoCo

## Что сделано

В проекте реализован REST API для расчёта бюджета.

Также добавлены тесты, которые проверяют:

- Обычный расчёт бюджета
- Расчёт со страховкой
- Отрицательное количество дней
- Нулевую стоимость дня
- Правильность расчёта дробных сумм

Во время тестирования была найдена ошибка в расчёте страховки. Вместо прибавления 5% программа умножала сумму на 5. Ошибка была исправлена.

## Как запустить

Открыть проект в IntelliJ IDEA и дождаться загрузки Maven.

Для запуска тестов выполнить:

```bash
mvn test
```

Для проверки покрытия кода:

```bash
mvn clean verify
```

Отчёт о покрытии находится в папке:

`target/site/jacoco/index.html`

## Результат

В проект добавлены автоматические тесты для проверки работы калькулятора. Проверяются правильные расчёты, обработка неверных данных и работа страховки.
